# Jonathan Jiménez — Astro Portfolio Context Pack

Este paquete contiene el contexto de producto, contenido, diseño y arquitectura para que Claude Code desarrolle el portafolio profesional de Jonathan Jiménez con Astro.

## Cómo usarlo

1. Descomprime este paquete en la raíz del repositorio donde se desarrollará el sitio.
2. Abre Claude Code en esa raíz.
3. Pídele que lea primero `00_PROJECT_BRIEF.md`, `01_CONTENT_AND_POSITIONING.md`, `02_INFORMATION_ARCHITECTURE.md`, `03_DESIGN_SYSTEM.md`, `04_ASTRO_TECHNICAL_GUIDE.md`, `05_CONTENT_SOURCE_OF_TRUTH.md` y `06_QUALITY_AND_ACCEPTANCE.md`.
4. Indícale que inspeccione el repositorio y proponga un plan de implementación antes de modificar archivos.
5. Proporciona por separado los dos PDF de CV si quieres que Claude contraste el contenido textual y prepare versiones descargables. Este paquete contiene el contexto extraído y confirmado, pero no incorpora los PDF originales.

## Índice

- `00_PROJECT_BRIEF.md` — objetivo, alcance y criterios generales.
- `01_CONTENT_AND_POSITIONING.md` — marca personal, narrativa y tono.
- `02_INFORMATION_ARCHITECTURE.md` — sitemap y navegación.
- `03_DESIGN_SYSTEM.md` — dirección visual y experiencia.
- `04_ASTRO_TECHNICAL_GUIDE.md` — stack, estructura y reglas técnicas.
- `05_CONTENT_SOURCE_OF_TRUTH.md` — trayectoria, formación, proyectos y tecnologías.
- `06_QUALITY_AND_ACCEPTANCE.md` — calidad, SEO, accesibilidad y aceptación.
- `07_CLAUDE_CODE_EXECUTION_PROMPT.md` — prompt inicial listo para Claude Code.
- `08_OPEN_ITEMS.md` — datos que deben permanecer pendientes o validarse.

## Regla fundamental

No inventar cargos, fechas, títulos académicos, métricas, clientes, resultados, funcionalidades ni estados de producción. Si un dato no está confirmado, omitirlo o marcarlo como pendiente de confirmación. No convertir una aspiración técnica en experiencia demostrada.
