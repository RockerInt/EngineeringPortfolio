## Context

Alwon is an operational intelligence platform for retail. I work on it as Founding Engineer, which means being close to both the architecture and the code that implements it.

## Where my work sits

My contribution spans the technical foundations of the platform:

- **Software architecture**: defining how the platform is structured and how its parts communicate.
- **Backend engineering**: services and APIs in TypeScript.
- **Systems integration**: connecting the platform with the systems that feed it.
- **Event processing**: moving and reacting to operational events through messaging infrastructure.
- **Data platforms**: the persistence and data layers the product is built on.
- **Artificial intelligence capabilities**: as part of the product's technical direction.

## Technology context

The platform is a TypeScript codebase organized as a monorepo. The web application is built with Next.js and React and runs on Cloudflare Workers; data lives in PostgreSQL through Supabase; the AI capabilities are built with LangGraph. Contracts are validated with Zod, and the code is tested with Vitest and Playwright.

## What this page leaves out

This is professional work on a private product, so this page is intentionally brief. Internal architecture, roadmap, customers, operational details and metrics are confidential and are not published here. I am glad to talk about the kinds of engineering problems involved in a conversation.
